# Documentation

This folder contains project documentation in two languages:

- English: [`./en`](./en)
- Français: [`./fr`](./fr)

## Priority

From now on, new documentation should be written primarily in English.
French documentation is kept and can be updated when needed.

## Scope

Documentation is based on:

- observed code behavior
- existing project files
- explicit project decisions

No speculative features should be documented as implemented.
